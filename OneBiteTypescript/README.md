# 한 입 크기로 잘라먹는 타입스크립트
> 이정환님의 ['한 입 크기로 잘라먹는 타입스크립트'](https://ts.winterlood.com/a1cada6f7b5a4628a11b1d4e33aef004) 강의를 보고 학습한 내용을 정리했습니다.

## 타입스크립트 개론
* MS의 엔지니어이자 C#의 창시자 앤더스 하일스버그에 의해서 탄생. C#과 비슷한 부분이 많음
* 타입스크립트는 오픈소스로 공개되어있고 많은 기여가 이루어지고 있어 발전가능성이 높음
* 해마다 인기가 많아지고 있음
  * [State Of JS 2024 - JS/TS balance](https://ts.winterlood.com/a1cada6f7b5a4628a11b1d4e33aef004)
* 타입스크립트는 왜 써야할까?
  * 자바스크립트는 원래 웹 브라우저 위에서 사용자 인터랙션을 위해 아주 간단하게 만들어짐
  * Node.js 탄생 이후 자바스크립트는 브라우저 밖 어디서든 구동 가능하게 됨
  * Node.js 런타임 아래 무엇이든 자바스크립트로 만들 수 있게 됨 (ex. 웹서버, 모바일 앱, 데스크탑 앱 등)
  * <p style="color: darkred; font-weight: bold;">자바스크립트의 유연한 문법이 버그 발생 가능성을 높여 안정성이 떨어짐</p>
  * <p style="color: darkred; font-weight: bold;">자바스크립트를 안전하게 사용할 수 있도록 타입 관련 안정적인 기능들을 추가하여 타입스크립트가 탄생하게 됨</p>
  * 타입스크립트는 타입 관련 기능들을 추가한 자바스크립트의 확장판이라고 볼 수 있음

## 타입 시스템
* 프로그래밍 언어를 사용할 때 타입과 관련해서 지켜야하는 규칙들을 모아둔 체계 (타입 문법 체계)
  * 값들을 어떤 기준으로 묶어 타입으로 규정할 것인가?
  * 코드의 타입을 언제 검사할 것인가?
  * 어떻게 타입을 검사할 것인가?
### 정적 타입 시스템
* **코드 실행 이전** 고정적으로 모든 변수의 타입을 결정
* 엄격하고 고정적인 시스템
* ex. C, Java
* 변수 선언시에 타입도 함께 결정
  * 타입을 잘못 사용했을때 **코드 실행 전 에디터상에서 오류 표시가 가능함**
  * 변수에 타입을 다 지정해야해야하기 때문에 타이핑양이 늘어남
### 동적 타입 시스템
* **코드를 실행하면서** 유동적으로 변수의 타입을 결정
* 자유롭고 유연한 시스템
* ex. JavaScript, Python
* 변수의 타입이 하나로만 고정되지 않음
  * **코드의 타입 오류를 미리 검사할 수 없음**
  * 메소드 사용 시 TypeError 발생 가능성이 있음
### 타입스크립트의 독특한 타입 시스템
* <p style="color: darkred; font-weight: bold;">정적 타입 시스템과 동적 타입 시스템을 혼합한 점진적 타입 시스템(Gradual Type System)</p>
* 정적 타입 시스템 모먼트
  * 변수의 타입을 실행 전에 결정
  * 타입 오류를 실행 전에 검사
* 동적 타입 시스템 모먼트
  * 모든 변수에 타입을 일일이 지정할 필요없음
  * 타입스크립트가 문맥을 통해 자동으로 타입을 추론
  * 자바스트립트로 컴파일 시 타입 선언을 생략

## 타입스크립트의 동작 원리
### 프로그래밍 언어의 일반적인 동작 원리
* 사람의 언어를 컴퓨터가 바로 이해할 수 없음
  * 사람: 한국어/영어 등으로 쓰여진 프로그래밍 언어 사용
  * 컴퓨터: 이진수, 바이트코드 등으로 이루어진 기계어를 사용
* 프로그래밍 언어에서 컴퓨터가 이해하기 쉬운 기계어 형태로 변환을 해서 컴퓨터가 실행함
* 기계어로 변환하는 과정을 컴파일(Compile) 이라고 함
* 컴파일 하는 친구를 컴파일러라고 함
### 컴파일러의 컴파일 과정
* [작성한 코드] -> [AST(추상 문법 트리)] -> 바이트 코드...
### 타입스크립트 컴파일 과정
* [타입스크립트 코드] -> [AST(추상 문법 트리)] -> 타입 검사
  * 타입 검사 실패 시 -> 컴파일 종료
  * 타입 검사 성공 시 -> 자바스크립트 코드로 변환 -> 컴파일 종료
* [타입스크립트가 컴파일 된 안전한 자바스크립트 코드] -> AST -> 바이트 코드 -> 실행
  * 타입스크립트에서 타입 검사가 성공한 코드는 타입관련 코드들이 컴파일 결과에서 사라짐
  * 타입스크립트를 설치하고 컴파일러(tsc)를 실행하면 자바스크립트 결과소스를 확인할 수 있음
